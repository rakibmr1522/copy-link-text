# Chrome Web Store Listing Draft

## Name
Copy Link Text

## Short description
Copy the main text of a link from the right-click menu, without copying its URL or extra source details.

## Detailed description
Copy Link Text adds a simple **Copy Link Text** option to Chrome's right-click menu. Right-click a link, choose the option, and the extension attempts to copy the link's main visible title or label.

### Features
- Fast right-click workflow
- Focuses on the main link title/text
- Attempts to exclude URL and breadcrumb metadata
- Simple design using the project's original blue-and-white logo
- No account required

### Notes
Results may vary on websites that use custom components, embedded frames, or protected content.
