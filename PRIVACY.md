# Privacy Policy — Copy Link Text

**Last updated:** October 24, 2026

Copy Link Text is a Chrome extension that copies the visible text associated with a link when the user chooses **Copy Link Text** from the right-click menu.

## Data collection

Copy Link Text does not intentionally collect, sell, or transmit personal information, browsing history, page contents, or clipboard contents to the developer or to a server.

## Local processing

When the user activates the context-menu action, the extension inspects the current page locally to identify the link text and copies the resulting text to the clipboard.

## Permissions

- `contextMenus`: adds the **Copy Link Text** right-click menu option.
- `activeTab`: allows interaction with the tab where the user invoked the action.
- `scripting`: reads link text from the active page after the user invokes the action.
- `clipboardWrite`: supports copying the text to the clipboard.
