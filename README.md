# Copy Link Text

![Copy Link Text](icons/icon128.png)

Copy Link Text is a simple Chrome extension that helps you copy the text of a link without copying its URL.

### Features
- Copy link text with a right-click.
- Simple and easy to use.
- Helps avoid copying unnecessary URLs.
- Lightweight and convenient.

### How to Use
1. Open a webpage in Chrome.
2. Right-click a link.
3. Select **Copy Link Text**.
4. Paste the copied text wherever you need it.

### Installation
1. Download or clone this repository.
2. Open `chrome://extensions/` in Chrome.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the extension folder containing `manifest.json`.

### Privacy
The extension is designed to work locally in your browser and does not intentionally collect or send browsing data to an external server.
